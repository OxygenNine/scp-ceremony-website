### 踩坑记录

1. **ZeoSeven 字体 CDN 拒绝 `127.0.0.1` 来源**：Referer 为字面 IP 时返回 204 空样式表，字体静默回退，**控制台无任何报错**。用 `localhost` 正常。本地预览必须 `--host localhost`。
2. **Astro 作用域样式不穿透子组件**：`<BrandMark class="hero__wordmark" />` 里的 class 在子组件内部不生效（缺 `data-astro-cid`）。改成父组件里包一层 div，或用 `:global()`。全局 `src/styles/*.css` 不受影响。
3. **pattern.monster 图形不在 DOM 里**，藏在某元素的 `background-image` data URI 中；取回后必须命名空间化 `id`，否则同页多个纹样会互相套用图案。
4. **B 站 `/x/space/arc/search` 需要 WBI 签名**，取不到 UP 投稿列表；搜索接口带 `buvid3` 即可用。
5. **沙箱 safe-delete shim 会拦 Astro 的 `.astro/dev.json` 清理**，导致 dev server 起不来；删掉该锁文件或改用静态服务器跑 `dist/` 即可。
6. 截图核验时若用 `127.0.0.1`，会因第 1 条误判成"沙箱问题"。**先查 Referer 规则再怀疑环境。**
